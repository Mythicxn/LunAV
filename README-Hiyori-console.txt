Hiyori - Developer Console + ẩn CMD

- main.js: Developer Console IPC, thu log console, resize cửa sổ.
- renderer.js: tách lịch sử chat khỏi debug log; USER / Virtual Assist; UI resize + Live2D.
- index.html: nút Developer Console và khu vực lịch sử chat.
- preload.js: bridge cho Developer Console/resize.
- developer-console.html: cửa sổ log kỹ thuật riêng.
- CHAY.bat + CHAY-an.vbs: chạy Hiyori ẩn cửa sổ CMD.

Lưu ý: giữ nguyên cai-dat.json hiện tại và thư mục models của bạn.
