# 🌿 LunAV — AI VTuber Companion

> An AI VTuber companion for chatting, voice interaction, Live2D, Discord and music.

LunAV is a desktop AI companion designed to combine an AI assistant with a Live2D VTuber character.

The project supports text chat, voice interaction, Discord integration, TTS, music playback and customizable Live2D models.
Download Now here : https://mythicxn.github.io/LunAV-webside/

====================================================================================================================================================

## ✨ Features

### 🤖 AI Assistant

- AI-powered conversation
- Text chat
- Context-aware conversations
- AI-generated emotional responses
- Emotion / expression control
- Screenshot and image interaction
- Customizable AI settings
- Conversation memory system

### 🌸 Live2D VTuber

- Live2D model support
- Mouse tracking
- Smooth head and body movement
- Expression control
- Interaction zones
- Touch / interaction reactions
- Custom Live2D models
- Model switching

Current project models include:

- `Akuro` (free)
- `Hiyori`(free)
- More will added soon
---

## 💬 Discord Integration

LunAV can connect to Discord and interact with users directly.

### Discord AI

- Respond when LunAV is mentioned/tagged
- English Discord responses
- Faster response path for Discord messages
- AI-generated replies
- Conversation handling

### 🎙️ Discord Voice

- Join Discord voice channels
- Leave voice channels
- Detect when users are speaking
- Voice activity tracking
- AI voice responses
- TTS playback inside Discord
- Voice reconnection handling
